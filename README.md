# Ringside

Website for **Ringside** (圈拍), an iPhone app for Taiwan's foreclosure auctions. You draw an area on the map,
and the app sends a notification when a court or the Administrative Enforcement Agency announces a new
property auction inside it.

Served by GitHub Pages at https://sona-orbit.github.io/ringside/

- Home, help and privacy pages in English and Traditional Chinese
- Static HTML and CSS, no build step on this repository
- Published by Sona Orbit. To report a problem, use "Report a Problem" in the app's Settings.
